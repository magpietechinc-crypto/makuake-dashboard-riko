# 소재 이미지 넣는 법

이 폴더에 파일을 넣으면 **소재별 성과** 탭에 그림이 나옵니다.

## 파일 이름 (이대로 저장해 주세요)

| 소재 이름 | 파일 이름 |
|---|---|
| 영상 C | `video_C.jpg` |
| 영상 B | `video_B.jpg` |
| 영상 A | `video_A.jpg` |
| 이미지 01 | `image_01.jpg` |
| 이미지 02 | `image_02.jpg` |
| 썸네일 | `thumbnail.jpg` |
| GIF 01 | `gif_01.jpg` |
| GIF 02 | `gif_02.jpg` |
| GIF 03 | `gif_03.jpg` |

**파일 이름을 바꾸지 마세요.** 화면이 이 이름으로 그림을 찾습니다.
이름을 바꾸고 싶으시면 `js/config.js` 의 `creativeAssets` 도 함께 고쳐야 합니다.

## 지금 들어 있는 것

Meta 광고 관리자에서 받아온 미리보기 이미지가 이미 들어 있습니다. 다만 **영상과 GIF는 160×160으로 작습니다.** Meta가 영상 미리보기를 그 크기까지만 내주기 때문입니다.

더 선명한 원본이 있으시면 **같은 이름으로 덮어써 주세요.** 화면은 정사각 틀에 맞춰 잘리지 않게 표시합니다.

## 형식

- `.jpg` 권장. `.png` 를 쓰시려면 `js/config.js` 의 파일 이름도 `.png` 로 바꿔야 합니다
- 정사각형(1:1)이 가장 깔끔합니다. 다른 비율도 잘리지 않고 들어갑니다
- 한 장에 1MB 이하를 권합니다. 9장이 한꺼번에 열리기 때문입니다

## 파일이 없으면

그림 자리에 점선 빈 칸이 나옵니다. 화면이 깨지지는 않습니다.
